# 🎬 Telegram Store Bot v2

Telegram ফাইল-স্টোর বট — নতুন করে সাজানো, বাগ ফিক্স করা এবং আরও অনেক ফিচার সহ।
পুরোনো `tmpb2hxvux6_haven.py` আগের মতোই আছে (রেফারেন্স হিসেবে), কিন্তু নতুন এন্ট্রি পয়েন্ট **`bot.py`**।

---

## 🚨 সবার আগে (একবারের কাজ)

পুরোনো কোডে টোকেন/সেশন সরাসরি লেখা ছিল এবং রিপো পাবলিক ছিল। তাই:

1. Telegram → **Settings → Devices** → অচেনা সেশন **Terminate** করুন।
2. **@BotFather → /mybots → API Token → Revoke** করে নতুন টোকেন নিন।
3. `config.env.example` কপি করে **`config.env`** বানিয়ে নতুন মান বসান (এই ফাইল গিট-এ যায় না)।

## ⚡ দ্রুত শুরু

```bash
cd /path/to/b
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

cp config.env.example config.env
nano config.env          # API_ID, API_HASH, BOT_TOKEN, ADMIN_IDS দিন

.venv/bin/python bot.py
```

শুরু হলে: বটকে `/start` দিন → **অ্যাডমিন প্যানেল** খুলবে।

> **হোস্টিং নোট:** বট একটা *সবসময় চলমান প্রসেস* — শেয়ার্ড হোস্টিং-এ সময়ে সময়ে প্রসেস বন্ধ হয়ে গেলে
> `cron` দিয়ে প্রতি ৫ মিনিটে আবার চালু করার লাইন দিন, অথবা VPS/container হোস্ট ব্যবহার করুন।
> `config.env`-এ `DB_FILE` এমন ফোল্ডারে রাখুন যেখানে লেখার অনুমতি আছে।

## 🗂️ প্রজেক্ট স্ট্রাকচার

```
bot.py                     # এন্ট্রি পয়েন্ট
config.env.example         # সব সেটিং এখানে (আসল ফাইল config.env, git-ignored)
app/
  config.py                # env পড়া + ভ্যালিডেশন
  logger.py                # রোটেটিং লগ + অ্যাডমিনকে এরর অ্যালার্ট
  runtime.py               # ক্লায়েন্ট, ক্যাশ, সেটিংস
  storage.py               # SQLite (WAL) + পুরোনো bot_db.json অটো-ইমপোর্ট + ব্যাকআপ
  payloads.py              # ডিপ-লিংক পার্সিং (নতুন + পুরোনো সব ফরম্যাট)
  keyboards.py / texts.py / ui.py / utils.py
  services/
    access.py              # প্রিমিয়াম/ফ্রি অ্যাক্সেস, ব্রডকাস্ট টার্গেট
    sender.py              # ফাইল পাঠানোর একটাই সার্ভিস (ডাইরেক্ট + JIT, noforwards সহ)
    scanner.py             # চ্যানেল স্ক্যান (সেশন ও বট-অ্যাডমিন দুই মোড)
    broadcast.py           # কিউ + FloodWait রিট্রাই + প্রগ্রেস
    scheduler.py           # ড্রিপ, লিংক GC, দৈনিক ব্যাকআপ, রিনিউ রিমাইন্ডার, সেশন ওয়াচডগ
    telegram.py            # সব API কলে রেট-লিমিট সেফটি
  handlers/
    router.py              # এক জায়গায় কলব্যাক রাউটিং (বাটন ডেটা ৬৪ বাইটের মধ্যে)
    user.py admin.py manage.py messages.py state.py
tests/                     # ৩১টা টেস্ট (নেটওয়ার্ক ছাড়াই চলে)
```

চালান:

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest tests -q      # ৮১টি টেস্ট, নেটওয়ার্ক লাগে না
```

`tmpb2hxvux6_haven.py` ফাইলটি আগের ভার্সন — রেফারেন্স হিসেবে রেখে দেওয়া হলো।
ওতে পুরোনো (আপনার রোটেট করা, এখন মৃত) টোকেন আছে; v2 লাইভ হওয়ার পর ফাইলটি মুছে দিতে পারেন।

- JIT টেম্প-কপি পাঠানোর পর ডিলিট — বটের DM আর ভরে না
- পুরোনো `bot_db.json` প্রথম চালুতেই অটো ইমপোর্ট — **পুরোনো সব লিংকও কাজ করে**

## 🛠️ পুরোনো ভার্সন থেকে মাইগ্রেশন

1. পুরোনো বট প্রসেস বন্ধ করুন (দুই বট একসাথে চললে দুজনেই উত্তর দেবে)।
2. `bot_db.json` ফাইলটা প্রজেক্ট ফোল্ডারে রেখে দিন।
3. `bot.py` চালু করুন — প্রথম রানেই সব ডেটা `bot_data.sqlite3`-এ চলে আসবে
   (স্টোর, ফাইল, প্রিমিয়াম অ্যাক্সেস, রেফারেল, ড্রিপ, সেশন, ফোর্স-জয়েন, লিংক)।
4. পুরোনো `bot_db.json` মুছবেন না — ব্যাকআপ হিসেবে রেখে দিন।

> স্টোরগুলো মাইগ্রেশনে **প্রিমিয়াম ধরে নেওয়া হয়** (আগের আচরণ অপরিবর্তিত রাখতে)।
> ফ্রি করতে প্যানেল থেকে স্টোর সিলেক্ট করে 🔒 বাটনে ট্যাপ করুন।
