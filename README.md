# 🎬 Telegram Store Bot + 🌐 Website (v3)

একটাই সিস্টেম, দুইটা রূপ — **টেলিগ্রাম বট** আর **ওয়েবসাইট**। দুইটাই একই ডেটাবেজ
ব্যবহার করে, তাই প্যানেলে যা করবেন বটেও ঠিক সেটাই।

| | কী | কোথায় |
|---|---|---|
| 🤖 | বট — ইউজার ফাইল পায়, প্রিমিয়াম কেনে, সাপোর্ট টিকেট খোলে | `t.me/<yourbot>` |
| 🌐 | পাবলিক সাইট — সব স্টোর, ডিপ-লিংক, সার্চ | `http://host:PORT/` |
| 🛠️ | অ্যাডমিন প্যানেল — ব্রডকাস্ট, ফাইল, অর্ডার, **সব সেটিংস** | `/admin` |
| ⚙️ | বটের অ্যাডমিন প্যানেল — সেশন, স্ক্যান, সেটিংস, ব্রডকাস্ট স্টুডিও | `/start` → প্যানেল |

## ⚡ দ্রুত শুরু

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements-web.txt      # বট + সাইট দুইটারই লাইব্রেরি

cp config.env.example config.env
nano config.env        # API_ID, API_HASH, BOT_TOKEN, ADMIN_IDS, WEB_PASS

.venv/bin/python run.py        # ⭐ বট + ওয়েবসাইট একসাথে
```

- শুধু বট: `python bot.py` · শুধু সাইট: `python -m web.dashboard`
- হোস্টিং প্যানেল (CodeNest / Render / Railway): start command **`python run.py`**,
  পোর্ট নিজে থেকেই `$PORT` ধরে নেয়।
- বট কানেক্ট না হলেও **সাইট চালু থাকে**; বট নিজে থেকেই আবার কানেক্ট হয়।
- বিস্তারিত ডিপ্লয়: **[DEPLOY.md](DEPLOY.md)** · এনভায়রনমেন্ট ভেরিয়েবলের ব্যাখ্যা: **[ENV.md](ENV.md)**

## ⚙️ সেটিংস — সব কিছু ওয়েবসাইট থেকেই (দরকার হলে বট থেকেও)

**config.env-এ শুধু ৪টা জিনিস লাগে:** `API_ID`, `API_HASH`, `BOT_TOKEN`, `ADMIN_IDS`
(+ `WEB_USER`/`WEB_PASS` লগইনের জন্য)। বাকি সব সেটিংস **ডেটাবেজে** থাকে — বটের
`⚙️ Settings` বা ওয়েবসাইটের `/admin/settings` থেকে বদলালেই সাথে সাথে কার্যকর,
**রিস্টার্ট বা ফাইল এডিট লাগে না**।

> মান কোথা থেকে আসছে সেটা প্যানেলে **badge** দিয়ে দেখানো হয়:
> `প্যানেল` (সেভ করা মান) · `config.env` · `ডিফল্ট`।
> নিয়ম: **প্যানেল > config.env > ডিফল্ট** — পুরোনো config.env সেটআপ অক্ষত থাকবে,
> প্যানেল থেকে সেভ করলে সেটা ওভাররাইড করবে। সব মান এক ক্লিকে
> `⬇️ config.env হিসেবে এক্সপোর্ট` করা যায়।

| গ্রুপ | কী কী বদলানো যায় |
|---|---|
| 📢 **চ্যানেল জয়েন** | চালু/বন্ধ, চ্যানেল, জয়েনের সময়ের বার্তা |
| 💳 **পেমেন্ট** | মুদ্রা, bKash, Nagad, Rocket, UPI, Crypto, নির্দেশনা, ট্রায়াল ঘণ্টা, ফ্রি প্ল্যান অটো-অ্যাপ্রুভ |
| 📞 **সাপোর্ট** | কন্টাক্ট (@username / নাম্বার / লিংক — যেকোনো কিছু), সময়, টিকেট কুলডাউন |
| 📝 **কনটেন্ট ও ভাষা** | ফাইলের ক্যাপশন, ডিফল্ট ভাষা |
| 📣 **ব্রডকাস্ট গতি** | বিরতি, ব্যাচ, লম্বা বিরতি, এক মেসেজে সর্বোচ্চ ফাইল, অটো-রিজিউম |
| 🌐 **ওয়েবসাইট** | সাইটের নাম, ট্যাগলাইন, টাইমজোন |

### 📢 চ্যানেল জয়েন — যেকোনো ফরম্যাট চলে

| আপনি লিখবেন | সিস্টেম বুঝবে |
|---|---|
| `@mychannel` / `mychannel` | পাবলিক চ্যানেল |
| `https://t.me/mychannel` | পাবলিক চ্যানেল |
| `https://t.me/+AbCdEfGhIj` | **প্রাইভেট ইনভাইট লিংক** |
| `https://t.me/joinchat/AAAAAE…` | পুরোনো ইনভাইট লিংক |
| `-1001234567890` | চ্যানেল আইডি |

- বট নিজেই চ্যানেল চিনে নেয়; না পারলে কানেক্টেড **সেশন** দিয়ে চেষ্টা করে (প্রাইভেট
  লিংকের জন্য এটাই লাগে)।
- প্যানেলে **🔎 চ্যানেল টেস্ট** চাপলে সাথে সাথে বলে দেয় চ্যানেল পাওয়া গেল কি না।
- নিরাপত্তা নিয়ম: চেক করা না গেলে ইউজারকে **আটকানো হয় না** (পেইং কাস্টমার আটকে যাওয়া
  অনেক খারাপ) — বরং বট ইনভাইট লিংক বাটনসহ “জয়েন করুন” দেখায়।
- ইনভাইট লিংক না থাকলে বট নিজেই একটা বানিয়ে নিতে পারে (**🔗 ইনভাইট লিংক**)।

## 🌐 পাবলিক ওয়েবসাইট (লগইন ছাড়াই)

| পেজ | কী দেখায় |
|---|---|
| `/` | সব স্টোর, ফাইল/সদস্য/ভিউ সংখ্যা, প্রতিটির **▶️ Telegram-এ খুলুন** ডিপ-লিংক |
| `/stores` | সম্পূর্ণ স্টোর লিস্ট |
| `/s/<slug>` | একটা স্টোর — ফ্রি স্টোরের ফাইল লিস্ট + প্রতিটির “পাঠান” লিংক |
| `/search?q=` | ফ্রি কনটেন্টে সার্চ |
| `/health` | আপটাইম মনিটরের জন্য JSON (বট অনলাইন কিনা সহ) |

🔒 **প্রিমিয়াম স্টোরের ফাইলের নাম সাইটে কখনো দেখানো হয় না** — শুধু “প্রিমিয়াম” লেখা
থাকে। ফাইল শুধু বটই পাঠায়, তাই কনটেন্ট সুরক্ষিত।

## 🛠️ অ্যাডমিন প্যানেল (`/admin`)

লগইন: `WEB_USER` / `WEB_PASS` (কুকি-সেশন; মনিটরিং স্ক্রিপ্টের জন্য HTTP Basic-ও চলে)।
`WEB_PASS` না দিলে সিস্টেম একটা টেম্পোরারি পাসওয়ার্ড বানিয়ে লগে লিখে দেয়।

- 📊 **ড্যাশবোর্ড** — ইউজার, ফাইল, স্টোর, ভিউ, আয়, পেন্ডিং অর্ডার, খোলা টিকেট,
  বট অনলাইন কিনা, সাম্প্রতিক ব্রডকাস্ট
- 📢 **ব্রডকাস্ট স্টুডিও** — নিচে বিস্তারিত
- 🗂 **ফাইল** — সব স্টোরে সার্চ, ডিলিট, প্রতিটি ফাইলের পাশে **📢** (ওই একটা ভিডিও ব্রডকাস্ট)
- 🏪 **স্টোর** — ফাইল/ভিউ/গ্রান্ট/আয়/প্ল্যান/ড্রিপ, সাইটে লিংক
- 🧾 **অর্ডার** — এক ক্লিকে ✅ অ্যাপ্রুভ / ❌ রিজেক্ট (অ্যাপ্রুভ করলেই ইউজারের অ্যাক্সেস চালু + নোটিফিকেশন)
- 👥 **ইউজার** — সার্চ, অ্যাক্সেস দেখা
- 📥 **এক্সপোর্ট** — SQLite, JSON, Users/Orders/Files CSV
- ⚙️ **সেটিংস** — উপরের সব গ্রুপ + `config.env` এক্সপোর্ট

### 📢 ব্রডকাস্ট স্টুডিও (উচ্চ পর্যায়ের)

- **প্রতি ভিডিওর জন্য ব্রডকাস্ট** — ফাইল ম্যানেজারে প্রতিটি ফাইলের পাশে 📢, আর
  ওয়েবসাইটের `/admin/files`-এও একই বাটন।
- **অডিয়েন্স সেগমেন্ট** — 📣 সব / 💎 প্রিমিয়াম / 🆓 ফ্রি / 🏪 নির্দিষ্ট স্টোরের সবাই /
  🔔 সাবস্ক্রাইবার / 🎯 **যারা কখনো কেনেনি** (win-back-এর জন্য সোনার খনি)।
- **কিউ ডেটাবেজে থাকে** — বট রিস্টার্ট/হোস্ট ঘুমিয়ে পড়লেও ব্রডকাস্ট হারায় না; বাকি
  ইউজারদের কাছে বাকি অংশ থেকেই যায়, কেউ **দুইবার পায় না**।
- **বট অফলাইন থাকলে** ক্যাম্পেইন `queued` থাকে → বট অনলাইন হওয়ামাত্র শিডিউলার নিজেই শুরু করে।
- 🧪 **টেস্ট সেন্ড** (নিজে আগে দেখুন) · 📅 **শিডিউল** · ⏹ **মাঝপথে স্টপ** ·
  🔁 **শুধু ফেল/ব্লক করা ইউজারদের রিট্রাই**
- `{name}` লিখলে প্রত্যেকের নাম বসে · ব্লক করা ইউজার মনে রাখে (পরের বার আর ট্রাই করে না)
- FloodWait হলে অপেক্ষা করে পাঠায়; ব্যাচ-পজ দিয়ে ৫,০০০+ ইউজারেও নিরাপদ
- লাইভ প্রোগ্রেস — বটের মেসেজে + ওয়েব প্যানেলে (৩ সেকেন্ডে অটো-রিফ্রেশ, `/admin/api/campaign/<id>`)

## 💾 ডেটা, ব্যাকআপ ও নিরাপত্তা

- সব ডেটা এক SQLite ফাইলে (`DB_FILE`, ডিফল্ট `bot_data.sqlite3`) — WAL মোড,
  তাই ক্র্যাশ হলেও ডেটা নষ্ট হয় না। পুরোনো `bot_db.json` প্রথম চালুতে অটো-ইমপোর্ট হয়।
- দৈনিক অটো-ব্যাকআপ (`BACKUP_DIR`, `KEEP_BACKUPS`) + প্যানেল থেকে তাই-ই ম্যানুয়ালি।
- প্যানেল → 📥 Export: SQLite, JSON, CSV (users/orders/files)।
- হোস্টিং প্যানেলে **ডেটা ব্যাকআপ/স্ন্যাপশট ফিচার চালু রাখুন** (CodeNest ডেটা ফাইল
  রিডিপ্লয়েও রেখে দেয়)।

### 🚨 নিরাপত্তা — এখনই করুন

1. **BotFather → `/mybots` → API Token → Revoke** করে নতুন টোকেন নিন। পুরোনো টোকেন
   রিপোর git history-তে আছে (এখন `config.env` ট্র্যাক করা হয় না, তবে পুরোনো কমিট মুছে না)।
2. `WEB_PASS` একটা শক্ত পাসওয়ার্ড দিন, `WEB_SECRET` একটা র‍্যান্ডম স্ট্রিং দিন।
3. প্যানেল পাবলিক রেখে পাসওয়ার্ড দুর্বল রাখবেন না — `/admin` পুরো স্টোর নিয়ন্ত্রণ করে।
